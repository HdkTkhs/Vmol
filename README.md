# Overview 
'Vmol' is a Fortran source code for the electronic density-functional theory (DFT) based on the real-space grid formalism. 'Vmol' was originally combined with codes (produced by third parties) for the classical molecular dynamics method to form a QM/MM simulator. However, in the current distribution, only the core of ithe 'Vmol' is being placed on GitHub. Thus, only the original KS-DFT machinery had been extracted from an integrated program. As a consequence, a lot of functions equipped on thecode had been disabled.
